# 💬 Free 聊天室

本地优先的 AI 角色扮演聊天 PWA。角色卡、世界书、正则规则、聊天记录全部保存在你自己的浏览器里，
无需注册登录，打开即用，可安装到手机/桌面当独立 App。

## ✨ 功能一览

- **角色系统**：文字表单创建/编辑角色（名称、头像、设定、性格、场景、开场白、备选开场、示例对话、标签），支持 **✨ AI 生成设定**（发送一次请求把名称与已有信息扩写成完整设定）
- **角色卡导入/导出**：JSON 格式，兼容酒馆（SillyTavern）角色卡 V2 结构（`data` 包裹、`first_mes`/`mes_example` 等字段）
- **流式聊天**：打字机效果、Markdown 渲染、消息编辑/删除/复制、重新生成（多版本 swipe 切换）、随时停止
- **候选回答**：每次 AI 回复后自动生成 3 条贴合双方人设的候选回答，点击即填入输入框；可在聊天设置中关闭
- **多份用户人设 + 角色绑定**：可创建多份人设，手动绑定到角色；与该角色聊天时自动使用绑定人设（未绑定用默认人设）
- **世界书（Lorebook）**：关键词触发注入设定，支持常驻条目、优先级、字符预算
- **自定义正则**：参考 SillyTavern 正则脚本——两种作用层（**仅显示** / **仅发给AI** / 两者）× 应用对象（AI回复 / 我的消息），支持 `$1` 捕获组、`/xxx/flags` 写法、实时测试预览
- **状态栏预设（v2）**：内置「好感度状态栏 / 回合信息面板 / 关系进度条」——正则页启用即**始终注入**；富卡片样式（脉冲圆点、扫光动画），更多属性（好感/心情/精力/时间/地点/事件），支持一键恢复默认
- **美化预设**：仿论坛帖子、微信红包、外卖订单、仿微信聊天记录卡片——在正则页**预览效果并认可**后，可在聊天页「扩展」里挂载；挂载后指令随请求注入，**由 AI 在合适的剧情里自行选用**
- **聊天抽屉**：聊天页右上角 🎛️/🧩 打开两个扩展页——「设置」（回复字数、**自定义文风框**（青春文艺/仿冰心/仿陀思妥耶夫斯基一键填充后可随意改）、剧情走向、辅助回复开关）与「扩展」（挂载美化、四种气泡样式：默认/QQ风/微信风/信纸风、聊天背景上传），全部按会话保存
- **4 套预设主题**：黑白极简（默认，白底）、浅绿清新、深蓝梦幻、红白极简 + 自定义 CSS
- **模型接入**：任意 OpenAI 兼容接口（OpenAI / DeepSeek / Kimi / 通义 / 中转站 / Ollama 等），内置**演示模式**（无需 API Key）；缺 Key/断网时明确报错并带超时保护
- **PWA**：可安装到主屏幕、离线打开应用壳、手机浏览器友好
- **数据自主**：一键导出/导入完整备份（JSON），随时清空

## 🚀 快速开始

```bash
npm install
npm run dev        # 开发模式，默认 http://localhost:5173
```

生产构建与预览：

```bash
npm run build      # 类型检查 + 生成图标 + 打包（含 Service Worker）
npm run preview    # 本地预览构建产物
```

## 📖 使用指南

1. **第一次玩**：默认是「演示模式」，新建角色 → 开始聊天即可体验完整流程。
2. **接入真实模型**：设置 → 模式选「OpenAI 兼容接口」，填 Base URL、API Key、模型名，点「测试连接」。
   - DeepSeek：`https://api.deepseek.com/v1` + `deepseek-chat`
   - 注意：接口需允许浏览器跨域访问（主流厂商基本都支持）。
3. **人设与绑定**：「人设」标签页可建多份人设（每份都支持 ✨ AI 生成）；在角色编辑页「绑定的用户人设」中选择后，与该角色聊天即自动生效。
4. **导入/导出角色卡**：首页「导入 JSON」，或在角色编辑页「导出 JSON / 导入 JSON 到表单」。
5. **世界书**：📖 图标进入，创建条目（关键词 → 内容），再到角色编辑页勾选绑定。
6. **正则与状态栏**：「正则」标签页。自定义规则示例：隐藏思考过程（查找 `/<think>[\s\S]*?<\/think>\n?/g`，替换留空，作用层「仅显示」）；状态栏预设开启开关即可，提示词与正则都可改。
7. **换主题**：设置 → 主题，四套预设一键切换；还可以写自定义 CSS。
8. **安装为 App**：浏览器菜单「安装 / 添加到主屏幕」。

## 🧱 技术栈

Vite + React 18 + TypeScript · Dexie (IndexedDB) · vite-plugin-pwa (Workbox) · marked + DOMPurify

无后端、无数据库服务：所有数据在浏览器 IndexedDB / localStorage 中，密钥只存本地。

## 📁 目录结构

```
src/
├─ main.tsx / App.tsx      # 入口、hash 路由、主题与自定义 CSS 注入
├─ types.ts                # 数据模型
├─ db.ts                   # Dexie 表定义（characters/sessions/messages/worldbooks/regexRules/personas/statusBars）
├─ components.tsx          # TopBar / TabBar / 通用组件
├─ lib/
│  ├─ llm.ts               # 流式对话（OpenAI 兼容 SSE + 演示模式）+ generateOnce + 候选回答
│  ├─ prompt.ts            # 人设解析、宏替换、世界书扫描、上下文组装（含状态栏注入）
│  ├─ regex.ts             # 正则规则编译与应用（显示层 / 提示词层）
│  ├─ statusbar.ts         # 状态栏预设与双层正则应用
│  ├─ cardfile.ts          # 角色卡 JSON 导入导出（酒馆 V2 兼容）
│  ├─ settings.ts          # 本地设置存取
│  ├─ markdown.ts          # Markdown + XSS 消毒
│  └─ img.ts / router.ts   # 头像处理 / hash 路由
└─ pages/                  # Home / CharacterEdit / Chat / PersonaPage / RegexPage / Worldbooks / SettingsPage
scripts/
└─ gen-icons.mjs           # 零依赖生成 PWA 图标
```
